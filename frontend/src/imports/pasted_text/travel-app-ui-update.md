현재 만들어진 여행 서비스 UI를 전체적으로 다시 구현한다.

중요:
이번 작업은 기존 1차 프로토타입을 버리고 완전히 새로운 디자인을 만드는 것이 아니다.
현재 만들어진 화면의 디자인 시스템과 여행 서비스 콘셉트를 유지하면서,
아래 수정사항을 모두 반영하여 실제 앱처럼 동작하는 수준으로 개선한다.

또한 첨부한 홈 화면 이미지를 홈 UI의 핵심 레퍼런스로 사용한다.

[첨부 이미지의 홈 화면 디자인을 참고할 것]

첨부 이미지처럼:
- 상단에 넓고 둥근 검색 영역
- 검색창 왼쪽 카테고리 선택
- 검색창 오른쪽 아이콘
- 화면 중앙에 큰 원형 기능 아이콘
- 기능들을 일정한 간격으로 그리드 형태 배치
- 하단에 페이지 이동 / 페이지 번호
- 전체적으로 화이트 기반
- 은은한 파스텔 그라데이션 배경
- 둥근 카드와 큰 터치 영역
- 복잡하지 않고 한눈에 기능을 이해할 수 있는 구조

를 여행 서비스에 맞게 적용한다.

단, 첨부 이미지의 취업/일자리 관련 콘텐츠를 그대로 복사하지 말고
여행 서비스의 기능으로 변경한다.

1. 전체 디자인 콘셉트
━━━━━━━━━━━━━━━━━━━━━━

전체 앱은 다음 디자인 시스템을 사용한다.

배경:
- White #FFFFFF
- 아주 옅은 Blue / Mint / Purple 계열의 은은한 그라데이션
- 화면 전체가 너무 화려하지 않도록 한다.

메인 컬러:
- Blue 계열
- 추천 메인 컬러: #4169D8 또는 유사한 Blue
- 선택된 버튼, 주요 CTA, 활성 아이콘 등에 사용한다.

카드:
- White
- border-radius 12~16px
- 그림자는 매우 약하게 사용

아이콘:
- Line icon 또는 단순한 Filled icon
- 기능을 직관적으로 이해할 수 있도록 한다.

폰트:
- Pretendard 또는 Noto Sans KR
- 제목은 굵게
- 본문은 읽기 쉽게
- 숫자와 날짜도 가독성이 높게 표현

버튼:
- 충분히 큰 터치 영역
- 최소 44px 이상의 터치 영역
- 주요 버튼은 화면에서 명확하게 구분

전체적인 느낌:
- 카카오T / 토스처럼 카드와 기능이 명확하게 구분되는 구조
- 하지만 여행 서비스답게 사진과 여행 정보를 적극적으로 활용
- 시니어도 쉽게 사용할 수 있도록 복잡한 메뉴를 최소화

핵심 특징:

- 상단의 큰 둥근 검색 바
- 검색창 오른쪽은 돋보기가 아닌 마이크
- 은은한 파스텔 그라데이션 배경
- 큰 원형 기능 아이콘
- 2~3열 기능 그리드
- 기능 이름을 아이콘 아래에 명확하게 표시
- 페이지 번호 / 좌우 이동
- 큰 터치 영역
- 깔끔한 여백
- 화이트 기반
- Blue 포인트 컬러
- 시니어가 한눈에 이해할 수 있는 구조

단,

34. 최종 프로토타입 우선순위
━━━━━━━━━━━━━━━━━━━━━━

모든 화면을 동일한 수준으로 만들지 않는다.

가장 높은 완성도로 구현해야 하는 화면:

1. 홈 화면
2. 사진 → AI 장소 발견
3. 장소 상세
4. 여행 조건 입력
5. AI 일정 결과
6. 오늘의 여행

특히 홈 화면과 AI 일정 결과 화면은
발표에서 가장 중요한 화면이므로
시각적 완성도를 가장 높인다.

전체 UI는 실제 여행 서비스 앱처럼 보이되,
불필요하게 기능을 많이 넣지 않는다.

핵심은:

"TV나 영상에서 본 장소를 발견하고,
나와 동행자에게 맞는 편안한 여행 일정으로 연결한다."

라는 서비스 경험이 한눈에 이해되도록 만드는 것이다.
